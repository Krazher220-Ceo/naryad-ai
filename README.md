# НарядAI

Система нарядов на ремонт для АО «Костанайские минералы» (кейс №1, Qostanai AI Industry Hackathon 2026).
Мастер выдаёт наряд с телефона, исполнитель принимает и закрывает его, ИИ проверяет выполнение и объясняет решение.

Все справочники и учётные записи — демонстрационные, сгенерированные. Это не реальные данные завода.

## Демо-логины

| Роль | Логин | ПИН |
|---|---|---|
| Мастер | `master1` | `111111` |
| Исполнитель | `worker1`, `worker2`, `worker3` | `222222` |
| Руководитель | `lead1` | `333333` |

## Запуск

Нужны Node.js 20+ и проект Supabase.

```bash
cd apps/web
npm install
cp ../../.env.example .env.local   # заполнить NEXT_PUBLIC_SUPABASE_URL и NEXT_PUBLIC_SUPABASE_ANON_KEY
npm run dev                         # http://localhost:3000
```

База данных (один раз на новый проект Supabase):

1. Выполнить по порядку файлы из `supabase/migrations/` в SQL Editor (или `npx supabase db push`).
2. Выполнить `supabase/seed.sql` — справочники и демо-логины.

## Проверки

```bash
cd apps/web
npm run typecheck
npm run lint
npm run build
```

## Структура

```
apps/web/            Next.js 16 (App Router), PWA — один код для мастера, исполнителя, руководителя
  app/(auth)/login   вход по логину и ПИН-коду
  app/(master)       панель смены, выдача, приёмка
  app/(worker)       мои наряды, закрытие
  app/(lead)         дашборд, рейтинг, отчёты
  lib/orders         переходы статусов наряда (единственное место)
  lib/ai             вызовы моделей, обезличивание
  messages/ru.json   все надписи интерфейса
  proxy.ts           проверка входа и роли на каждом запросе
supabase/migrations  схема базы, правила доступа (RLS)
supabase/seed.sql    минимальные справочники и демо-логины
```

План работ — `PLAN.md`, правила для разработчиков и ИИ-агентов — `AGENTS.md`, использованные ИИ-инструменты — `AI_TOOLS.md`.

## Как устроен вход

Логин превращается в служебный адрес `<логин>@naryad.local`, ПИН из 6 цифр служит паролем Supabase Auth.
Роль сотрудника хранится в таблице `employees`. `proxy.ts` отправляет каждого на экран его роли,
а доступ к данным проверяет база через правила RLS, а не скрытие кнопок.

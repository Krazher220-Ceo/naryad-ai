## Дополнения для Claude Code

- План проекта — в `PLAN.md`. Читай нужный раздел, весь файл перечитывать не нужно.
- Для задач больше чем на один файл сначала включи режим планирования и покажи план.
- В этом репозитории параллельно работает Antigravity. Перед правкой общего файла проверь `git status` и `git log -5`, чтобы не затереть свежие изменения.
- После изменений запусти проверку типов и линтер из раздела «Команды» в `AGENTS.md`. Если команды ещё не заполнены, заполни их при создании проекта.
- Не делай коммит и не отправляй изменения в удалённый репозиторий без просьбы.
- Если правило из `AGENTS.md` мешает выполнить задачу, остановись и спроси, а не обходи его.
- Интерфейс v2 делай по наброскам на холсте (ссылка в начале `PLAN.md`, раздел 8). Если экрана нет на холсте или он расходится с кейсом, спроси, а не придумывай.
- Android: собирай APK оболочкой TWA в `apps/android`. Нативный код без просьбы не пиши. Если он появится (например, из Google AI Studio), проверяй, что в нём нет своей логики статусов, прав и подсчётов, а все данные идут через функции базы и серверные маршруты. Ключ подписи не коммить.
- Перед правкой экрана проверь его на ширине 360 px и на ПК. Если изменение касается телефона, напиши, проверено ли оно в Android-приложении.
- Локальные модели (Whisper, Qwen3) работают на Mac команды. Любой новый вызов модели — через `lib/ai` с запасным путём, чтобы жюри не увидело ошибку, когда Mac выключен.

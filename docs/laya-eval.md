# Laya на русских описаниях нарядов — результат теста

Дата: 3 октября 2026. Открытый вопрос из PLAN.md, раздел 11.

**Как проверяли.** 20 вымышленных описаний нарядов на русском (services/fast-ai/eval.py), для каждого
заранее записаны правильные категория шифра (М/Э/Г/П/С), приоритет и специальность.
Laya — чекпойнт `laya-multilingual` (пакет `laya` 0.3.25, без дообучения), MacBook Air M2.
Для сравнения те же 20 описаний классифицировала `deepseek-flash` с коротким описанием категорий.

| | Laya, вопросы по-русски | Laya, вопросы по-английски | DeepSeek |
|---|---|---|---|
| Категория шифра | 9/20 (45%) | 13/20 (65%) | 20/20 (100%) |
| Приоритет | 6/20 (30%) | 7/20 (35%) | 15/20 (75%) |
| Специальность | 5/20 (25%) | 11/20 (55%) | 20/20 (100%) |
| Время на запрос | 111 мс | 73 мс | ~2,2 с |

**Выводы.**
- Без дообучения Laya на нашем домене слабая, и бывает уверенно неправа
  («Искрит электрощит» → сварщик с вероятностью 0,96). Порог уверенности это не спасает.
- Приоритет спорный и для людей: даже DeepSeek расходится с разметкой в 5 случаях из 20.
- Авторы Laya пишут, что дообучение на своих решениях резко поднимает точность
  (0,362 → 0,766 на их тесте). Данные для дообучения у нас будут: генератор M3 даёт 500+ размеченных нарядов.

**Решение до дообучения.** Подсказку шифра, приоритета и специальности делает DeepSeek (источник `llm`).
Laya подключается к той же функции и становится основным путём после дообучения и повторного теста.

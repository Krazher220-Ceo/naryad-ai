# ИИ-инструменты и внешние компоненты

Список по требованию положения хакатона (п. 5.8 и 6.4). Каждая новая зависимость добавляется сюда.

## ИИ-инструменты разработки

| Инструмент | Назначение |
|---|---|
| Claude Code (модель Claude Opus 5.5) | Архитектура, схема базы и правила доступа, ревью всего кода, слияние веток |
| Claude Code, субагенты на Claude Sonnet 5.5 | Реализация модулей по спецификации (вход по ПИН, маршрутизация по ролям) |
| Antigravity (`agy`) | Задачи с чёткими границами: PWA, вёрстка экранов, скрипты. Результат проверяется человеком и Claude Code перед слиянием |

Весь код, написанный с помощью ИИ, проверяется командой. Команда может объяснить любой фрагмент.

## ИИ в самом продукте

Все вызовы моделей идут через `apps/web/lib/ai`. ФИО сотрудников заменяются метками до отправки,
с фото удаляются метаданные. Если модель недоступна, вердикт выносят правила кода (`needs_master` там, где без модели решить нельзя).

| Модель / компонент | Где работает | Назначение |
|---|---|---|
| DeepSeek `deepseek-flash` (API) | облако, режим `AI_PROVIDER=cloud` | Соответствие работ проблеме, сравнение фото «до/после», пояснение вердикта, подсказка шифра и приоритета |
| Ollama + мультимодальная модель (план) | свой компьютер, режим `local` | Тот же набор задач без отправки данных наружу |
| Laya `laya-multilingual` (Convai Innovations, Apache 2.0), пакет `laya` (PyPI) | `services/fast-ai`, свой сервер | Быстрая классификация описания: категория шифра, приоритет, специальность с вероятностями. Пока без дообучения точность низкая, см. `docs/laya-eval.md` |

## Зависимости приложения (`apps/web`)

| Пакет | Назначение |
|---|---|
| next, react, react-dom | Веб-приложение и PWA |
| tailwindcss, @tailwindcss/postcss | Стили |
| typescript, eslint, eslint-config-next | Проверка типов и линтер |
| @supabase/supabase-js | Доступ к базе, хранилищу и Realtime |
| @supabase/ssr | Сессия Supabase в cookie для серверных компонентов и proxy |
| server-only | Защита: серверный код с секретами не попадёт в браузер |
| qrcode, @types/qrcode | QR-коды оборудования для быстрого выбора при выдаче наряда (уровень коррекции H, со значком в центре) |

## Зависимости `services/fast-ai`

| Пакет | Назначение |
|---|---|
| laya[serve] (тянет torch, transformers, fastapi, uvicorn) | Запуск Laya и HTTP-сервер |

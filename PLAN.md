Кейс №1 хакатона Qostanai AI Industry Hackathon 2026, заказчик — АО «Костанайские минералы».
Полный текст кейса: `Кейсы/1 кейс - Костанайские минералы/Кейс №1 Костанайские минералы рус.pdf`. При любом сомнении прав кейс, а не этот файл.

## 1. Что строим

Система нарядов на ремонт. Оператор сообщает о поломке по QR-коду, мастер выдаёт наряд с телефона или ПК, исполнитель принимает и закрывает его, ИИ следит за сроками, проверяет выполнение по тексту и фото, считает рейтинг и ищет закономерности в истории. Руководитель видит сводку, аналитику и управляет пользователями.

Наше отличие — двухслойный ИИ-контролёр:

- **Быстрый слой (Laya).** Открытая модель решений на нашем сервере. По тексту определяет категорию шифра, приоритет и нужную специальность, возвращает вероятность.
- **Медленный слой.** Мультимодальная модель сравнивает фото «до» и «после», языковая модель объясняет результат человеку.
- **Вердикт с доказательствами.** ИИ отдельно пишет, что видно, что сошлось и что проверить нельзя. Финальное решение всегда за мастером.
- **Голос, как диктофон.** Речь → Whisper → модель раскладывает разговорный текст по полям наряда. Без сети работает распознавание телефона.

Клиенты: веб-приложение (PWA) для ПК и телефона и Android-приложение (APK) поверх того же кода. Все клиенты работают с одной базой и синхронизируются в реальном времени.

- Экран исполнителя: все кнопки статусов, фото, комментарии, шифры, материалы

## 4. Архитектура

```
Клиенты
  apps/web (Next.js, PWA)        ПК и телефон, все 4 роли + оператор без входа
  apps/android (APK)             оболочка над apps/web (TWA), тот же код и та же база
        |
        |-- Supabase              PostgreSQL, вход, хранилище фото, Realtime, pg_cron
        |-- Next.js /api, actions серверные действия и маршруты: наряды, заявки, отчёты, ИИ
        |-- services/fast-ai      наш Mac (сейчас MacBook Air M5 16 ГБ):
        |                           Laya, Whisper large-v3-turbo, Qwen3-4B (Ollama)
        |-- облачный ИИ           DeepSeek, только с обезличиванием, запасной путь
        |-- Telegram Bot API      уведомления вне приложения
```

| Слой | Технология |
|---|---|
| Клиент | Next.js 16 (App Router), React 19, TypeScript, Tailwind 4, PWA |
| Android | TWA (Trusted Web Activity), сборка Bubblewrap, `apps/android` |
| База и вход | Supabase: PostgreSQL, Auth, Storage, Realtime |
| Быстрый ИИ | Python, FastAPI, Laya (Apache 2.0) |
| Голос | Whisper large-v3-turbo (MIT) через mlx-whisper (MIT) на Mac |
| Языковая модель | Qwen3-4B-Instruct-2507 (Apache 2.0) через Ollama (MIT); облако DeepSeek — запасной путь |
| Фото | мультимодальная модель через `lib/ai` |
| Уведомления | в приложении (центр уведомлений) и Telegram-бот |
| Хостинг | Vercel для приложения, наш Mac для `services/fast-ai` |

Ключевые решения:

- **Один код для всех клиентов.** Android-приложение — оболочка TWA над тем же адресом. Права, переходы статусов и проверки живут в базе и серверных действиях, поэтому клиент не может их обойти. Если команда соберёт нативный клиент (например, в Google AI Studio), он работает только через те же функции базы и маршруты, без своей логики, и лежит в `apps/android`.
- **Источник ИИ переключается** в настройках (`settings.ai_provider = local | cloud`). В облачном режиме ФИО заменяются на номера до отправки и подставляются обратно после ответа.
- **ИИ никогда не останавливает работу.** У каждого вызова таймаут и запасной путь: Mac недоступен → облако; облако недоступно → правила кода и вердикт `needs_master`. Laya — таймаут 1,5 секунды.
- **Голос в два шага.** Аудио с телефона уходит на `services/fast-ai` → Whisper даёт текст → Qwen3-4B возвращает строгий JSON с полями наряда → человек проверяет поля и подтверждает. Без сети или без Mac — распознавание браузера, текст вставляется без разбора; разбор выполняется, когда связь появится.
- **Контроль сроков по расписанию раз в минуту.** `pg_cron` в Supabase вызывает `/api/cron/deadlines` с секретом.
- **Вход по логину и паролю** через Supabase Auth: логин превращается в служебный адрес. Пароль не короче 8 символов, буквы и цифры. Сброс пароля делает руководитель.
- **Оператор без входа.** Заявку принимает серверный маршрут, а не прямая запись в таблицу. Проверяется настоящий QR, обязательное ФИО, ограничение частоты (не больше 5 заявок с одного телефона за 10 минут). ФИО оператора не уходит во внешний ИИ.
- **QR ведёт по роли.** Один адрес `/q/<код>` для машины, цеха или группы инструмента. Сервер смотрит, кто вошёл: оператор → заявка, исполнитель → свой наряд на этой машине или просмотр, мастер → выдача с выбранной машиной, руководитель → карточка машины.
- **Офлайн.** Service worker кэширует оболочку приложения и последние открытые экраны. Наряды, справочники и фото, снятые без сети, хранятся в IndexedDB. Каждое действие имеет `client_action_id`, повтор не создаёт дубль.
- **Все надписи из словарей** `messages/ru.json` и `messages/kk.json`. Сервер берёт язык через `getT()`, клиент через `useT()`. Telegram, тексты для модели и выгрузки — на русском (`tRu`).

### Статусы наряда

Десять статусов из кейса плюс отмена, которую кейс требует в пункте 5.1.

| Код | Название |
|---|---|
| `issued` | Выдан |
| `accepted` | Принят в работу |
| `queued` | В очереди |
| `rejected` | Отклонён |
| `in_progress` | В работе |
| `paused` | Приостановлен |
| `done` | Исполнено |
| `ai_review` | Проверка ИИ |
| `rework` | На доработку |
| `closed` | Закрыт |
| `cancelled` | Отменён мастером |

Допустимые переходы:

```
issued      -> accepted | queued | rejected
queued      -> accepted
accepted    -> in_progress        (после проверки безопасности)
in_progress -> paused | done
paused      -> in_progress
done        -> ai_review          (автоматически)
ai_review   -> closed | rework    (решает мастер, ИИ рекомендует)
rework      -> in_progress
rejected    -> issued             (мастер переназначил)
любой до closed -> cancelled      (только мастер)
```

Просрочка — это не статус, а вычисляемый признак: `due_at < now()` и статус раньше `done`.
Отклонение и пауза требуют причину. Время паузы с причинами «ждёт запчасть», «ждёт допуск», «ждёт остановки оборудования» в просрочку исполнителю не засчитывается.

### Статусы заявки

`new` (ждёт мастера) → `converted` (выдан наряд, есть ссылка на него) или `dismissed` (отклонена с причиной). Решает только мастер. Оператор видит статус в «Мои заявки».

### Роли и права

| Роль | Что может | Вход |
|---|---|---|
| Оператор | Заявка о поломке по QR, свои заявки | без входа (ФИО обязательно) или общий логин участка |
| Исполнитель | Свои наряды и наряды бригады: принять, очередь, отказ, начать, пауза, исполнено, помощь, попутная находка | логин и пароль |
| Мастер | Выдача, переназначение, приоритет, закрытие, доработка, отмена, оценка, заявки, отчёты, помощник, QR, сроки | логин и пароль |
| Руководитель | Всё, что видит мастер, плюс аналитика, пользователи, роли, сброс пароля, режим ИИ, справочники | логин и пароль |

Права проверяет база (RLS и функции), а не скрытие кнопок.

## 7. ИИ-модули

Правило: всё, что можно посчитать, считает код. Модель используется, чтобы понять текст, речь или фото и чтобы объяснить результат словами.

| Модуль | Вход | Выход | Чем | Без модели |
|---|---|---|---|---|

| Шифр, приоритет, специальность | описание проблемы | класс и вероятность | Laya, затем языковая модель | мастер выбирает сам |
| Подбор исполнителя | специальность, допуск, смена, нагрузка, рейтинг | кандидаты с пояснением | код | — |

| Речь → текст | аудио | текст | Whisper large-v3-turbo (Mac) | распознавание браузера |
| Разбор речи | текст | поля наряда или заявки (JSON) | Qwen3-4B (Mac), облако | текст без разбора |

Локальные модели на Mac (MacBook Air M5, 16 ГБ): Whisper turbo около 1,6 ГБ, Qwen3-4B в 4-битном виде около 2,5 ГБ, Laya — меньше 1 ГБ. Вместе около 5 ГБ.

Формат ответа проверки фото:

```json
{
  "same_equipment": {"value": true, "confidence": 0.92, "evidence": "..."},
  "visible_problem_before": "...",
  "visible_problem_after": "...",
  "repair_visible": true,
  "quality_findings": ["..."],
  "cannot_verify": ["..."],
  "score": 4,
  "confidence": 0.78,
  "verdict": "accept | accept_with_note | rework | needs_master"
}
```

Формат ответа разбора речи:

```json
{
  "equipment_hint": "НШ-2",
  "problem": "Течь масла по сальнику",
  "priority": "emergency | high | normal | planned | null",
  "fault_code": "Г-01 | null",
  "assignee_hint": "Ахметов | null",
  "confidence": 0.81
}
```

Оборудование и исполнитель из ответа модели сверяются со справочником кодом. Если совпадения нет, поле остаётся пустым.

Если уверенность ниже порога (`settings.ai_confidence_threshold`, по умолчанию 0,7), вердикт — `needs_master`. ИИ не выдумывает оценку.

Рейтинг включает все пять составляющих из кейса: качество 35%, в срок 25%, без возвратов и повторных поломок за 7 дней 20%, объём 10%, без отказов 10%. При числе нарядов меньше 5 — пометка «мало данных».

## 8. Интерфейс v2

### 8.1 Общие правила

- **Стиль km.kz.** Тёмно-синий `#001636` и `#07316e`, синий `#1753a9`, голубой `#d4e4fd`, жёлтый акцент `#ffc107`. Заголовки — Oswald, текст — Inter. Логотип — `public/brand/km-logo.svg`, класс `km-logo`. Цвета статусов и приоритетов не фирменные, они закреплены в `AGENTS.md`.
- **Телефон.** Шапка: логотип и заголовок слева, плашка связи и колокольчик со счётчиком справа. Внизу три кнопки, средняя крупная и приподнята:

  | Роль | Слева | По центру | Справа |
  |---|---|---|---|
  | Оператор | Заявки | Сканер | Профиль |
  | Исполнитель | Наряды | Сканер | Профиль |
  | Мастер | Смена | Выдать | Помощник |
  | Руководитель | Сводка | Аномалии | Профиль |

  На экранах одного наряда нижнего меню нет: одно главное действие внизу на всю ширину.
- **ПК.** Тёмное меню слева (компонент `Sidebar`): белая карточка с логотипом, пункты роли со счётчиками, внизу блок аккаунта — ФИО и роль, колокольчик, «Связь» (плашка на всю ширину), «Язык» (две кнопки «Русский» / «Қазақша»), «Выйти». Всплывающие сообщения на ПК — слева внизу, над аккаунтом.
- **Плашка связи.** Четыре состояния: «В сети» (зелёная), «Отправка · N» (синяя), «Нет сети · N» (серая), «Ошибка · N» (красная). Нажатие открывает очередь отправки.
- **Центр уведомлений.** Колокольчик открывает список с непрочитанными, «Прочитать все». Те же события, что уходят в Telegram.
- **Касание.** Кнопки от 56 px, вторичные от 48 px. Переключатели — две большие кнопки, а не мелкие ссылки.

## 12. Открытые вопросы

- **Android.** Основной путь — TWA (раздел 4). Если команда решит собрать нативный клиент в Google AI Studio, он обязан работать только через функции базы и серверные маршруты, и команда должна уметь объяснить его код. Решение — за Алиханом до начала M8
- **Mac во время проверки жюри.** Модели на MacBook Air работают, только пока он включён и доступен из интернета (туннель). Если нет — облако или правила; проверить заранее, что жюри не увидит ошибок
- Адрес, на который отправляется письмо со сдачей
- Справочники демонстрационные. Реальных шифров и нормативов завода в открытом доступе нет, на защите это говорится прямо
- Казахский перевод нужно вычитать (Али)
